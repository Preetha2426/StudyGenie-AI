# 🎓 StudyGenie AI

## Personalized Study Planner using Generative AI

StudyGenie AI is an AI-powered educational assistant developed using **Python**, **Gradio**, and **GPT-4.1 Nano**. It helps students prepare for exams by generating personalized study plans, explaining topics, creating revision notes, solving doubts, generating quizzes, and providing answer keys.

---

## 🚀 Features

- 📅 Personalized Study Planner
- 📖 Topic Explanation
- 📝 Revision Notes
- ❓ AI Doubt Solver
- 🧠 AI Quiz Generator
- ✅ Answer Key Generator

---

## 🛠 Technologies Used

- Python
- Google Colab
- Gradio
- OpenAI Python SDK
- GPT-4.1 Nano

---

## 📋 Workflow

1. Enter Subject and Topics.
2. Select Days Remaining and Study Hours.
3. AI generates:
   - Personalized Study Plan
   - Topic Explanation
   - Revision Notes
   - Practice Quiz
   - Exam Tips
4. Use AI Doubt Solver for instant clarification.
5. Generate quizzes and answer keys for self-assessment.

---

## 📌 Project Outcome

StudyGenie AI simplifies exam preparation by providing personalized learning support using Generative AI. It saves students time and helps them prepare more effectively through interactive AI-generated content.
